# U.S. Constitution in Akoma Ntoso

The Constitution of the United States and its 27 amendments in Akoma Ntoso XML, with a CSS stylesheet that renders the document in a parchment style in a web browser. It was generated by Claude for Grant Vergottini and published on Election Day, November 3, 2026.

## Files

| File | Purpose |
| --- | --- |
| `us-constitution.xml` | The Akoma Ntoso document |
| `us-constitution.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Structure:** The original text is an `<act>`, with the signatures in `<conclusions>`. The amendments are in an `<attachment>` with their own metadata.
- **Signatures:** The 40 signatures are base64-encoded PNG images embedded in `<img>` elements within `<signature>`. Each has a `<person>` element with the transcribed name.
- **Rendering:** Browsers do not draw Akoma Ntoso `<img>` elements, so the CSS repeats the signature images as backgrounds. The XML remains the source of the images.
- **Page breaks:** Only the break before the fourth parchment page is marked.

## Sources

- Text: U.S. National Archives transcriptions of the [Constitution](https://www.archives.gov/founding-docs/constitution-transcript), the [Bill of Rights](https://www.archives.gov/founding-docs/bill-of-rights-transcript) and [Amendments 11-27](https://www.archives.gov/founding-docs/amendments-11-27). Spelling and punctuation follow those transcriptions.
- Signatures, state names and parchment texture: the National Archives [high-resolution scan](https://www.archives.gov/founding-docs/downloads) of page 4.
- Editorial notes on amendments are from the National Archives and are kept in the document metadata.

## Fonts

The stylesheet embeds Pinyon Script, UnifrakturCook and IM Fell English, all licensed under the [SIL Open Font License](https://openfontlicense.org/). The script and blackletter fonts approximate the original hand; they do not reproduce it.
